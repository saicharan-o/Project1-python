# Daily Practice Problems Archive

This archive contains historical daily coding exercises, data science exercises, algorithm experiments, and visual plots, including:

- **NumPy Core Fundamentals**: Vectorized operations, multidimensional slicing, broadcasting, linear algebra exercises (`Numpy_B.py`, generated figure plots).
- **Pandas Manipulation**: Data cleaning, indexing, aggregation, grouping, pivot tables (`Pandas_B.py`).
- **Machine Learning Foundations**:
  - One-Hot Encoding (`CAR_OHE.py`, `OHE.py`)
  - Decision Trees & Random Forest Experiments (`D-T.py`, `Exercise_Random_Forest.py`)
  - Support Vector Machines (`SVM.py`, `E-SVM.py`)
  - Logistic Regression (`Logistic.py`, `M-LOG.py`, `E-LOG.py`)
  - Gradient Descent Optimizers (`Gdescent.py`, `GradT.py`)
- **Algorithms & Puzzles**: Palindrome checks, sum computations, zero matrices.
- **Datasets**: Historical CSV files for Canada income, HR attrition, hiring scores, car prices, and Titanic survival.
